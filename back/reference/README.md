# 기존 참고 데이터

Phase 폴더 정리 시 기존 추적 사진·JSON·SVG를 삭제하지 않고 이동한 자료입니다.
운영 작업은 `ART_JOB_PLAN_ROOT/<job_id>`에 생성하며 이 참고 데이터와 분리합니다.

- `kiosk/confirmed_outputs/`: 기존 확인 선화와 이력
- `lineart/samples/`, `lineart/outputs/`: 입력 샘플과 선화 결과
- `path_planner/outputs/`: 기존 경로 JSON·SVG·시각화 결과

과거 JSON은 참고 자료이며 현재 작업으로 자동 등록되지 않습니다.
